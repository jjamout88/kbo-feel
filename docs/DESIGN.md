## 0. 한 줄 컨셉
나스닥 선물(게임 속 이름 "바나나스닥")로 대박 난 내가 **KIA 타이거즈를 인수**하고, **9번 타자로 데뷔해 4번 타자 겸 감독**으로 한국시리즈 MVP까지 간다.

- 플랫폼: **아이폰 가로 웹게임** (GitHub Pages, 홈 화면에 추가하면 전체화면 앱, 오프라인 플레이 가능)
- 한 판 = 한 시즌 (정규 18경기 + 가을야구), 약 60~80분. 끝나면 칭호만 남고 새 시즌 (로그라이크)
- 직접 조작은 **승부처 미니게임 4종뿐**: 타격 / 수비 위기 / 홈 쇄도 / 도루. 나머지는 전광판 빨리감기
- 경기 밖에서는 감독으로 **타순(내 자리)·기용(휴식)·훈련** 3가지만 결정

## 3. 화면 흐름
```
타이틀 → 타자 만들기 → 오프닝(3컷)
  → [브리핑 → 경기(전광판 + 승부처) → 결과 → 보상 카드 → (이벤트/올스타) → 팀 관리] × 18
  → 정규시즌 결과 → (5위 안) 가을야구 라운드 안내 → [관리 → 브리핑 → 경기 → 결과 → 보상] 반복
```

## 6. 경기 엔진
- 타석 단위 자동 진행. **출루 확률 = 0.31 + (공격 전력 − 수비 전력) × 0.45**
- 출루 시: 볼넷 20 / 단타 55 / 2루타 15 / 3루타 2 / 홈런 8 (%). 아웃 시: 삼진 30 / 땅볼 40(주자 1루·2아웃 미만이면 병살 35%) / 뜬공 30(3루 주자·2아웃 미만이면 희생플라이 50%)
- 내 자동 타석(승부처 아님): 출루 = 0.22 + 0.16×(타격 종합/99) − 0.03(에이스)
- 무승부 없음 (연장 최대 15회)
- **KIA 전력** = 0.435 + 관리 보너스(0~0.05) + (내 종합 − 50)/99 × 0.03 − 0.015(종합 65 미만인데 4번) − 지친 주전 1명당 0.01 − 백업 출전 0.005 (+ 이벤트 버프)
- 상대 에이스: 정규 33%, 가을야구 60% (상대 전력 +0.01). 브리핑에 미리 표시
- 가을야구 상대 전력 +0.02

### 6-1. 승부처
| 내 타순 | 1·2·5 | 3·4 | 6·7 | 8·9 |
|---|---|---|---|---|
| 기본 승부처 수 | 3~4 | 4~5 | 3~4 | 2~3 |
- **최소 3번 보장** (모자라면 수비·주루로 채움), 최대 5번. 구단주 특별 지시 카드 +1, 발야구 카드 주루 +1
- 종류: 타격 60 / 수비 20 / 주루 20 (주루는 홈 쇄도·도루 반반)
- 1~8회에 흩어 배치 (같은 회 중복 없음)
- 9회 추가: 내 팀 공격인데 0~2점 지고 있으면 타격, 수비인데 1~2점 앞서 있으면 수비 위기. **한국시리즈는 9회 ±3점이면 무조건 내 타석**
- 셋업: 타격은 주자가 나간 뒤 내 타석 / 수비는 득점권 주자가 나간 뒤 내 쪽 타구 / 홈 쇄도는 내가 2루타 → 다음 타자 안타 / 도루는 내가 단타로 1루
- 성공 판정: 타격 = 출루하거나 타점 / 수비 = 아웃 / 주루 = 세이프
- 홈 경기 + 팬 신뢰 70 이상이면 응원 버프 (성공 확률 +4%p, 시뮬 기준)

### 6-2. 화면 연출
- 승부처가 아닌 구간: **전광판 빨리감기**. 이닝별 득점판(1~9회·득점·안타), 현재 회·아웃·주자, 내 승부처 기록(성공/실패 아이콘 + 남은 수), 오늘 내 타격 기록, 득점 장면 자막. 타석당 0.12초, KIA 득점 0.55초·상대 득점 0.4초 멈춤. 자동 구간은 경기당 약 20초
- 승부처: "승부처!" 배너 + 상황(회·아웃·주자·점수차) → 탭하면 미니게임 → 성공/실패 배너 → 빨리감기 재개
- 관중 밀도 = 팬 신뢰 (전광판 위 관중 띠, 타격 화면 관중석)

### 7-1. 타격 판정 (`app/js/mg_bat.js`)
- 판정 폭(GOOD) = 150ms × 컨택배율. 오차가 이보다 크면 헛스윙 (v1.6에서 110 → 150ms로 넉넉하게)
- 타구 품질 q = (1 − 오차/GOOD)^1.4 × (존 밖 공이면 0.5) × (에이스면 0.8)
- q > 0.55: 62% 안타(품질 높으면 2루타, 파워 비례 홈런) / 나머지 정면 아웃
- q 0.3~0.55: 단타 20% · 파울 34% · 아웃 46%
- q < 0.3: 빗맞은 안타 5% · 파울 47% · 아웃 48%
- 퍼펙트: 홈런 (5% + 38%×파워)(1 − 0.35×에이스), 2루타 30%, 3루타 3%, 나머지 단타
- 볼 4개 볼넷(성공), 스트라이크 3개 삼진. 2스트라이크 파울은 카운트 유지
- 번트: 존 안 공 80%(번트 작전 95%), 존 밖 30%(60%) 맞힘 → 번트 안타 (15% + 35%×주력)(번트 작전 1.5배), 아니면 주자 있으면 희생 번트·없으면 아웃
- **타이밍 링**: 공이 던져지면 스트라이크 존 가운데 원(반지름 16) 둘레에서 큰 원(반지름 62)이 줄어들어, 정답 스윙 순간에 가운데 원과 정확히 겹침. 링 색 = 지금 치면 받을 판정(흰색 = 헛스윙 / 초록 = 판정 폭 절반 안 / 노랑 = 퍼펙트). 정답 순간이 지나면 흐려지며 사라짐. 에이스는 링이 공 진행 42% 지점부터 나타남(읽을 시간 짧음). 스윙하면 그 순간의 링을 0.45초 남겨 얼마나 빨랐는지·늦었는지 보여줌
- 스윙 후 "저스트! / 조금 빨랐다 / 너무 늦었다" 표시

### 7-1b. 수비 판정 (`app/js/mg_field.js` 상수 `FB`, v1.5 추가 완화)
- **탭한 지점으로 달려감** (손 떼도 계속, 끌면 목표 이동). 노란 원('여기로')이 목표 위치를 알려줌. `FB.snap: true`로 바꾸면 아무 데나 탭해도 노란 원으로 자동 이동(v1.5에서 써봤다가 재민 피드백으로 뺌)
- 타구가 날아가는 동안 **카메라 고정** (나와 목표 지점이 한 화면에)
- 이동 속도 = 50(내야)·48(외야) + 24×수비/99 px/초. 포구 반경 = 8 + 4×수비/99, 다이빙 반경 = 포구 + 10 + 5×수비/99 (수비 시프트 1.3배, 쉬움 1.25배)
- 땅볼 속도 60 px/초, 뜬공 체공 3.0초 (에이스면 빨라짐), 타구 전 준비 1초
- 송구 게이지: 바늘 왕복 2.2초(내야)·2.4초(외야), 초록 폭 0.36·0.32 + 0.14×수비/99, 노란 정중앙 9% = 무조건 아웃. 다이빙 캐치면 초록 80%. 6번 왕복하면 자동 실패

### 7-2. 실측 성공률 (`tools/calib.py`: 봇이 실제 게임을 자동 플레이해 측정)

## 8. 팀 관리 (경기 후 매번)
| 탭 | 하는 일 | 효과 | 권한 잠기면 |
|---|---|---|---|
| 타순 | 9칸 중 내 자리 선택. 코치 추천 칸은 노란 테두리 | 타순 = 승부처 수. 실적보다 2칸 이상 높으면 낙하산(신뢰 −6/경기) | 코치가 나를 9번에 |
| 기용 | 9명(나 포함) 중 1명 휴식. 땀 아이콘 = 지침 | 지친 선수 휴식 신뢰 +2, 안 지친 선수 +1(신인 기용). 나를 쉬면 승부처 없이 자동 경기 | 코치가 지친 선수를 50% 확률로 휴식 |
| 훈련 | 포인트 1 = 능력치 +2, 또는 팀 훈련 1단계(전력 +0.005, 최대 6단계 = +0.03). "되돌리기" 가능 | | 코치가 자동 배분, 효율 50% |
- **코치 추천 타순**: 신뢰 80↑·종합 65↑ → 4번 / 70↑·58↑ → 3번 / 60↑·52↑ → 5번 / 50↑ → 7번 / 그 외 9번
- **낙하산** = 내 자리가 5번 이내이면서 추천보다 2칸 이상 높음
- **관리 보너스**(최대 0.05) = 타순 적정 0.01 + 지친 주전 없이 출전 0.01 + 팀 훈련 최대 0.03
- **컨디션**: 동료는 4연속 출전 후 매 경기 12%로 지침, 지친 선수는 매 경기 25% 자연 회복. 나는 4연속 후 30%로 지침, 지치면 미니게임 능력치 −6. 올스타 때 전원 회복
- **훈련 포인트**: 경기당 2 + 승리 1 + 신뢰 70↑ 1 − 신뢰 30↓ 1 (+평상시대로 카드 1). 정규시즌만
