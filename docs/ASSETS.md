# 에셋 목록 v1.0

모든 그림은 PNG 없이 `app/js/gfx.js`가 실행 중에 도트로 그려서 캐시함. 그래서 팀 색·피부·등번호·좌우타 교체가 코드 한 줄이고 용량이 0.
에셋 미리보기: `tools/sheet.html` (브라우저로 열기). 앱 아이콘: `python3 tools/make_icons.py`

## 아트 규칙
- 논리 해상도 **320×148** (아이폰 가로 844×390을 2.6배로 확대). 전부 정수 좌표, 보간 없음
- 광원 왼쪽 위. 부위마다 5단 팔레트 [외곽 / 어둠 / 기본 / 밝음 / 하이라이트]
- **외곽선은 검정 금지**, 같은 계열 가장 어두운 색 (남색 계열은 #0a0e24가 최저)
- 상승 = 빨강 `#ff4a5a`, 하락 = 파랑 `#4aa8ff`
- 캐릭터는 파워프로식: 머리·몸통·손·발만, 팔다리 없음. 눈은 세로 타원, 코 없음

| 테마 3종 | — | 홈(노을 + 초록 펜스), 원정(남색 + 남색 펜스), 돔(키움, 보라 펜스) |

## 컷신 그림
차트 모니터(캔들 애니, 상승/급락) · 구단 인수 계약서(서명 애니 + 도장) · 타이거즈 일보(헤드라인 신문) · 트로피 · 종이 꽃가루 · 비 내리는 구장

## 글꼴
갈무리 11 Bold / 11 / 9 (OFL). **반드시 12px / 12px / 10px로만** 사용(그 외 크기는 획이 깨짐).
KS X 1001 한글 2,350자 + ASCII로 잘라서 woff2 3개 합계 130KB (원본 13MB).
